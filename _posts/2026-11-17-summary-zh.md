### [Neo4j Virtual Graph 正式可用](https://neo4j.com/blog/news/neo4j-virtual-graph-is-now-generally-available/) ⭐️ 8.0/10

Neo4j 宣布 Virtual Graph 已在 Neo4j Aura 的 GCP 环境正式可用，AWS 和 Azure 支持仍是后续计划。该产品将 Cypher 查询转译为 SQL 并在数据仓库或湖仓中执行，面向 Snowflake、Databricks、Google BigQuery 和存储于 S3 的 Apache Iceberg 表，无需复制或迁移数据即可构建知识图谱并支持 GraphRAG、欺诈检测和供应链分析；多 TB 数据规模及治理收益属于厂商描述，材料未提供性能验证或客户案例。

rss · Neo4j Blog · 11月16日 17:25

**「背景」** 传统知识图谱通常需要先把数据导入图数据库；Virtual Graph 则在现有仓库表上建立图模型，并将 Cypher 查询转为仓库端 SQL 执行。文章称，连接时沿用所提供角色的权限，因此现有行级限制与数据掩码仍适用。

**「建模启示」** 产品将图建模与查询执行分开：用户可手动定义图模型、从数据库 schema 生成，或在 Aura 组织启用 AI 后根据表元数据生成并审核修改；查询阶段则以确定性转换将 Cypher 下推为 SQL。连接使用用户提供的仓库角色凭据，材料称现有角色、行级限制和数据掩码仍适用，这为在既有数据平台权限边界内增加图查询能力提供了具体设计参考。
