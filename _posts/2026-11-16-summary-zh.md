### [中科院自动化所等推出 RSI 综述](https://www.jiqizhixin.com/articles/2026-11-15-3) ⭐️ 6.0/10

据机器之心报道，中科院自动化所、美团等推出 RSI 综述，从 Prompt 优化到 Harness 进化梳理智能体持续改进的发展思路，并以三个问题、七步生命周期组织讨论。所给摘要以编程 Agent 遭遇 API 参数更新、尝试修复后能否在后续任务中避免重犯为例，说明其关注的是如何将任务经验转化为持续改进。这一议题可供企业编程助手及其他需跨任务积累经验的智能体平台研究参考，但当前材料仅为截断摘要，未提供综述原文、具体方法、实验数据或落地证据，无法据此判断技术效果与可实施性。

rss · 机器之心 · 11月15日 08:47

**「背景」** 材料用编程 Agent 遇到 API 参数变更、经多轮尝试修复报错的假设场景，引出 RSI 所关注的问题：一次任务中获得的经验，能否转化为后续任务中的持续改进。当前提供的媒体摘要仅提到从 Prompt 优化到 Harness 进化的梳理框架，以及“三个问题、七步生命周期”，尚未展示具体方法、评估结果或实际部署证据。

**「研究启示」** 摘要中的 API 报错案例提示，企业智能体评估应区分“当前任务修复成功”与“后续任务能否复用经验”，不能仅凭单次成功判断其具备持续改进能力。综述覆盖从 Prompt 优化到 Harness 进化的范围，也为平台设计提供了一个考察维度：改进对象不只包括提示词，还包括智能体的运行支撑机制；但摘要尚不足以支持具体架构选型。
