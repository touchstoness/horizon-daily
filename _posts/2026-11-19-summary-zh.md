### [Unity Gateway Insights 分析 Agent 成本](https://www.databricks.com/blog/introducing-unity-gateway-insights) ⭐️ 8.0/10

Databricks 于 2026 年 11 月 18 日推出 Unity Gateway Insights，面向已通过 Unity Gateway 运行编码 Agent 的团队，使用 Genie 分析数百万条 Agent traces，并结合业务数据和本体，识别重复 MCP 错误、简单任务调用高价模型及可转为共享技能的重复工作流。用户可生成最近 1 天、7 天或 30 天的报告，为报告添加最多 10 个自定义问题，并查看关联会话的 traces；Databricks 称其内部修复常见 MCP 错误预计每年可节省 120 万美元，这属于厂商自述。

rss · Databricks Blog · 11月18日 22:42

**「背景」** Databricks 表示，完整分析 Agent 工作流需要记录会话中的输入输出、工具调用、子 Agent、中间步骤、延迟和 token 成本；单独的网关只能记录经过它的请求。该产品将采样会话并按工作类型分组，再检查 MCP 工具故障、上下文膨胀、简单任务使用前沿模型和重复工作流，并按涉及的 token 量排序。

**「平台启示」** 这项设计把运行时可观测性与业务数据、本体及治理结合起来，并将异常发现关联到具体 traces，便于从成本信号追查工具或工作流问题。报告还支持自定义问题并继续向 Genie 提问，体现了从预设诊断到交互式分析的产品路径。

## Agent 协议与开发生态

<a id="item-protocols-1"></a>
### [OpenAI Agents SDK 0.25.0 更新](https://github.com/openai/openai-agents-python/releases/tag/v0.25.0) ⭐️ 7.0/10

OpenAI 发布 Agents SDK v0.25.0，移除了 beta Runloop 沙箱提供方；使用 Runloop 的团队需迁移至其他受支持的提供方（例如 Modal），或暂留 0.24.0，并单独迁移提供方专属的会话与快照数据。此版本还支持在 RunState schema 1.22 下恢复带输出护栏的嵌套 Agent 工具审批，并改为在 Pydantic 检查点中保留默认值和原地编辑；共享检查点的多工作进程应用应先升级读取端。压缩会话默认模型改为 gpt-6-luna，需保持此前选择时可显式设置 gpt-4.1；这些变化适用于依赖该 SDK 的沙箱任务、持久化工作流及工具审批流程。

github · openai-sdks\[bot\] · 11月18日 00:22

**「背景」** Horizon 于 2026-11-17 的日报摘要报道，Agents SDK v0.24.0-alpha.8 已支持在检查点恢复时保留部分待处理工具请求和审批信息；本次 v0.25.0 则进一步说明可恢复嵌套 Agent 工具审批，并由 RunState schema 1.22 支持。

**「集成启示」** 升级涉及检查点读写兼容性和沙箱会话数据迁移：共享检查点时应先升级读取端，切换 Runloop 时则需单独处理提供方专属数据。使用进程内资源的 Pydantic 检查点应配置自定义序列化器。
