**「背景」** 此前，Python Agents SDK 的模型提供方由 Runner 的运行配置决定；本次预览通过 CodexProvider 将 Codex 作为可选提供方接入，并允许同一 Agent 在不同运行中使用不同提供方。SDK 直接复用嵌入 wheel 的 Codex Core，避免启动 codex app-server 及使用 JSON-RPC；每次调用创建新线程，历史记录则由 SDK session 管理。

**「集成启示」** 该版本体现了“Agent 编排层与模型执行内核分层”的集成方式：上层保留 Runner、工具、审批和会话管理，底层通过可替换的 provider 接入 Codex Core。对企业平台而言，按运行注入模型提供方并显式管理线程、会话历史和 provider 生命周期，可为多模型路由与资源回收提供清晰边界。
